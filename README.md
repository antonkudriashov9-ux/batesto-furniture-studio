# Batesto · демонстрация сайта и 3D-студии

Независимая демонстрационная концепция для Batesto. Не официальный сайт мастерской.

## Запуск и публикация

- Локально: `python -m http.server 8765 --directory dist`, затем `http://localhost:8765/`.
- 3D-студия: `/studio/`. Актуальный CAD-эталон — 358 деталей.
- Проверки: Node.js 24, `node --test *.test.mjs`.
- GitHub Pages: Settings → Pages → Source: GitHub Actions. Workflow публикует только `dist/` при обновлении `main`.
- Исходники CAD: `cad/build_reference.py`; готовая STEP-сборка скачивается в ZIP.
- Источники материалов и ограничения прав: [ATTRIBUTION.md](ATTRIBUTION.md).


Статический сайт без сборки. Файлы публикации в dist/.

Функции: каталог концепций с фильтрами, подробный просмотр, избранное в браузере, перенос идеи в конструктор, 4 шага настройки, схема фасада/вида сверху, размеры и отделка, комплектация, сохранение/восстановление проекта, создание задания, копирование и скачивание TXT. Контакты ведут на публичные страницы мастерской.

Конструктор 2D на главной странице не рассчитывает стоимость и не отправляет заявки. Для реального расчёта нужны расценки мастерской, для приёма заявок — согласованный канал и серверная интеграция. Данные проекта хранятся только в браузере после явного сохранения. Избранное сохраняется при нажатии сердца.

Интерьерные изображения — AI-концепции, это указано на сайте. Они не являются портфолио мастерской. Баннер workshop.jpg — с публичной страницы Batesto. Перед публичным коммерческим запуском нужно согласовать материалы, условия и права использования с Вадимом, заменить концепции реальными работами при наличии разрешения. Демонстрационная публикация предназначена для просмотра и обсуждения с мастерской.

Проверка доменной логики: node --test project.test.mjs. Проверка синтаксиса: node --check dist/app.js.


## Batesto Studio 2 — /studio/

Отдельный редактор на Three.js 0.180.0, WebGL 2. Локальные библиотеки и PBR-карты: редактор не зависит от CDN при работе. Физический свет, мягкие тени, отражения окружения, карты цвета, нормалей и шероховатости, скруглённые кромки мебели.

Реализовано:
- 12 типов модулей и готовые компоновки; точные размеры в мм, перенос, поворот, копирование, закрепление, скрытие и удаление с отменой.
- Переключение «Модуль / Деталь». Двойной щелчок и список деталей: фасады, ручки, боковины, дно, задняя стенка, полки, перегородки, столешница, мойка, смеситель, техника, подсветка. У детали собственные размеры, смещения XYZ, поворот, материал, цвет, направление и масштаб текстуры, видимость.
- «Размер»: цветные маркеры меняют выбранный модуль или деталь мышью. «Двигать»: перенос детали по X/Z; вид спереди — X/Y. Точные значения всегда доступны справа.
- Правая кнопка: выбор детали, перенос, размер, поворот, открывание, свет, техника/вода, копия, блокировка, скрытие, удаление. В режиме деталей поворот и перенос относятся к детали; удаление в меню явно относится ко всему модулю.
- Распашные, подъёмные, раздвижные и откидные фасады; полное/частичное выдвижение ящиков. Отдельное открывание фасада/ящика, шесть типов ручек, секции, полки; доводчик записывается в спецификацию.
- Духовка, конфорки, холодильник, смеситель и свет с состоянием включения; у техники и мойки смоделирован внутренний объём.
- Размеры прямоугольной комнаты, отделка и цвета стен, пола, фартука и плинтуса; масштаб/направление текстуры, шероховатость, толщина стены, окно и дверь с размерами, положением и открыванием; свет и экспозиция.
- 3D, план сверху и фасад спереди; сетка и шаг привязки; проверка пересечений габаритов модулей и выхода из комнаты.
- Автосохранение, история, именованные копии, проверяемый JSON импорт/экспорт, PNG, CSV со спецификацией и настройками деталей, OBJ видимой мебели (геометрия без материалов).

Ограничения: это визуальный параметрический планировщик, не производственная CAD/CAM. Нет раскроя, присадки, расчёта прочности, автоматической проверки траекторий дверей, совместимости конкретных артикулов фурнитуры, коммуникаций и столкновений отдельных деталей. Произвольные смещения/размеры могут нарушить конструкцию. Коллизии относятся к номинальным габаритам модулей. Цена и отправка заявки не подключены; проект и копии хранятся в браузере. Для передачи между localhost и опубликованным сайтом используйте JSON.

Проверка: node --test project.test.mjs studio.test.mjs studio-details.test.mjs. Синтаксис всех studio JS/MJS проверен Node. В браузере проверены перетаскивание и изменение размеров модуля/детали, индивидуальная ручка и открывание ящика, контекстное меню, включение духовки, окно/дверь/пол, отмена и экспорт JSON/CSV/OBJ; 390 px без горизонтального переполнения.

Источники решений и терминологии:
- https://grabsketch.com/en/help — порядок планирования, комната и модули.
- https://help.roomsketcher.com/hc/en-us/articles/360000358905-How-Do-I-Change-the-Material-or-Color-on-Kitchen-Cabinets-and-Countertops — индивидуальные материалы и фасады.
- https://www.blum.com/us/en/products/ — категории фурнитуры. В редакторе используются обобщённые механизмы, без заявления о совместимости с артикулами Blum.
- Источники и лицензии PBR-карт: dist/assets/pbr/SOURCES.md.


## Studio PRO — актуальное обновление 29.10.2026

Вход: `/studio/`. Предыдущие JSON-проекты совместимы; текущая кухня хранится на устройстве. Для переноса между localhost и опубликованным сайтом — Экспорт → JSON → Мои проекты → Импорт.

- **Модуль → Точная сборка · PRO**: стрелки XYZ и кольцо поворота для модуля или выбранной детали; точные размеры/координаты в существующих свойствах. Привязка к соседям, линии фасада, стенам (включая наклонные), регулируемый зазор, привязка высоты навесного шкафа. По желанию перенос блокируется при пересечениях.
- Выбор нескольких модулей через Shift/Ctrl или список флажков, группы, выравнивание фасада/верха/левого края. Группа переносится вместе; вращение гизмо выполняется относительно выбранного модуля. Закреплённые модули не двигаются.
- Дерево деталей, визуальная разборка, связанные размеры индивидуальных деталей при изменении габаритов. Пределы пролёта полки и ширины фасада задаются пользователем. Проверка открывания — приближённая зона перед фасадом, не точная траектория конкретной петли.
- Покрытия: матовое, лак, пластик, шпон и металл; отдельная кромка и зазор фасадов. PBR-карты локальные, масштаб текстур физический. Качественный снимок повышает разрешение и карту теней, затем восстанавливает рабочие настройки; это real-time WebGL, не path tracing.
- **Комната → Контур, проёмы и коммуникации**: произвольный простой многоугольник, Г-образный пресет, отдельные материалы стен, несколько окон/дверей/проходов, колонны и выступы, точки коммуникаций. Стены со стороны камеры автоматически скрываются. Ввод стен и проёмов нумеруется с 1.
- Подложка PNG/JPEG/WebP загружается локально, калибруется двумя точками и известным размером; можно менять положение, угол и прозрачность. Изображение уменьшается до 1200 px, JSON ограничен 3 МБ; сжатые ссылки просмотра исключают подложку.
- **Проект и смета**: свой каталог с артикулами/категориями/единицами/ценами, назначения на каждый модуль и количество фурнитуры. Пустая цена неизвестна, явный ноль допустим. Учтённая сумма всегда помечена неполной, пока есть пропуски. Расход приблизительный, без отходов раскроя и доставки. Реальные данные Вадима не предоставлены и не выдуманы.
- PDF A4: план, развёртки каждой стены с проёмами, размеры, спецификация и расчёт. Кириллица включается растровыми страницами; текст не выделяется. CSV и JSON остаются машиночитаемыми. PDF не является рабочими чертежами производства.
- До 12 версий на устройстве: сохранить, сравнить, восстановить (с отменой), удалить (с возвратом до закрытия страницы). Ссылка содержит неизменяемый снимок проекта и открывается в режиме просмотра. «Редактировать копию» сначала создаёт резервный проект в «Моих проектах». Ссылка не меняет права доступа сайта; localhost работает только на этом компьютере.

Остаются границы продукта: нет раскроя, присадки, проверки прочности и совместимости официальных артикулов. Коллизии модулей считаются по номинальным габаритам; произвольно смещённые детали могут выходить за них. Производственные решения подтверждает мастер.

Проверка PRO: `node --test project.test.mjs studio.test.mjs studio-details.test.mjs studio-pro.test.mjs studio-room-pro.test.mjs`. Синтаксис всех JS/MJS. Browser QA: XYZ-перенос/отмена, группировка, покрытие, контур и проём, загрузка/калибровка подложки, каталог/сумма, версии/сравнение, PDF, PNG высокого разрешения, режим просмотра без записи в автосохранение. Тестовые изменения отменены.

Итог проверки PRO: 29 тестов проходят. Независимый обзор выполнен; три найденных дефекта исправлены и проверены повторно. Проверка нового интерфейса на 390 px не подтверждена: доступный встроенный браузер сохранил ширину 1280 px после запроса изменения viewport.


## Materials update — 2026-11-02

- 24 authored finish profiles: six wood variants from two CC0 scans, six enamels, four stone finishes, four metals and four glass finishes. These are appearance presets, not manufacturer SKUs or certified physical samples.
- Library dialog provides filtering, search, a real 3D sample under common HDR lighting, roughness adjustment, explicit Apply and reset. Separate module assignments for fronts, carcass, worktop and handles; detail assignments and batch application to the same detail kind respect locked modules.
- Physical UV coordinates are refreshed after part scaling; optional continuous front mapping and X/Y offsets preserve grain density. Wood tint overrides work. Edge material and thickness are independently editable on supported panels/fronts.
- Drawer bottom, sides, back and runners; hinges, lift hardware and glass inserts now have their own selectable IDs. Facade changes preserve these nested materials. Closed-part dimensions stay stable while the facade opens.
- Part focus/isolation are transient viewing operations. Fine geometry controls are collapsed by default. Library profiles are also available for floor, common walls and the backsplash on wall 1, including Pro room openings.
- JSON/history retain assignments and overrides. CSV/brief names reflect module profile selections. Room Pro supports inheriting the common wall finish.

Limits: real-time raster rendering with HDRI and screen-space contact shadows, not a path-traced final renderer. Mechanism collision checks remain approximate; no new rigid-body/structural solver. Appliances remain parameterized generic models. Catalog models, KTX2 conversion and manufacturer-specific hardware compatibility are separate future work. Glass uses approximate screen-space transmission; the preview is not a production material sample.

## Простой режим и разборка
По умолчанию показаны основные настройки. Кнопка «Расширенные настройки» открывает точные инструменты. «Разобрать и настроить детали» изолирует выбранный модуль: плавная разборка/сборка, ползунок, два способа расположения, поиск и категории деталей. Материалы и параметры выбираются для каждой смоделированной детали. Разборка не меняет проектные координаты и экспорт OBJ; это визуализация устройства, не физический расчёт креплений. Учтён prefers-reduced-motion.

## Каталог и фурнитура
43 редактируемые конфигурации на основе 19 поддерживаемых конструкций. Категории помещений и поиск; миниатюры готовятся по мере появления в списке. Разборка имеет уровни узлов и деталей, последовательные этапы и выключаемые линии сборки. Исследование профессиональных решений: docs/professional-reference.md. Проверено 69 тестами и через интерфейс (замена ручки, петли, добавление шкафа, отмена).


Новые узлы, крепления, крупный план и диагностика открывания: [описание и ограничения](docs/studio-upgrades.md).
